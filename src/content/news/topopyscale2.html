Mountain Futures has released TopoPyScale 2, an open-source tool that turns coarse global climate data into weather for real mountain terrain. Version 0.1.2 is free to use under the MIT licence, with prebuilt installers for Linux, macOS and Windows.

Why it matters

Global reanalysis such as ERA5 describes the weather in grid cells about 31 km across. In the mountains, one cell can span valleys and summits more than 2,000 m apart, but the reanalysis sees smooth ground at a single elevation. Snow, water, ecology and hazard studies need the conditions on the actual slopes: how cold it is at 3,000 m, how much sun a north face gets, whether the precipitation falls as rain or snow.

TopoPyScale 2 bridges that gap. It groups the terrain from a 30–90 m elevation model into units of similar elevation, slope, aspect and sky view, and gives each unit its own hourly temperature, humidity, wind, shortwave and longwave radiation, and precipitation split into rain and snow.

What is in this release

A downscaling engine for ERA5, with the physics written in Python and in Rust for speed. A local web page (tps2 ui) to choose an area on a map, set the period and the downscaling options, run, and view the result, without editing configuration files. A results page (tps2 view) for any run: each variable on the terrain, against elevation, and through the season, in a single file that works offline.

Alongside whole areas, TPS2 can downscale to named points such as weather stations or field sites. Each point gets its own forcing, with slope, aspect, horizon and sky view taken from the terrain around it.

It ships with a worked example — a full season above Davos, Switzerland, where one ERA5 grid cell becomes 150 terrain units between 1,041 and 3,097 m. It can be opened without installing anything, and rebuilt or re-run step by step. Measured limitations are published with numbers, so users can judge a result before relying on it.

TopoPyScale 2 runs on Linux, macOS and Windows with Python 3.11 to 3.13, and ERA5 is read from Google's public archive, so no account is needed. Installers are on the latest release page; the documentation lives in the repository.

Built on a decade of research

TopoPyScale 2 is a ground-up rewrite of TopoPyScale (Filhol, Fiddes and Aalstad, 2023), and implements methods published as TopoSCALE (Fiddes and Gruber, 2014) and TopoSUB (Fiddes and Gruber, 2012). It is developed by Joel Fiddes (Mountain Futures) and Simon Filhol (Météo-France).

In operation

The same engine already drives SnowMapper, Mountain Futures' daily snow forecasts for several mountain regions.

Snow modelling, station validation, data assimilation, forecasts and climate scenarios exist in development and will be released as they mature; the repository's roadmap lists them.

Get involved

Questions, bug reports and feature requests are welcome as GitHub issues. Researchers using TopoPyScale 2 are asked to cite it using the citation file in the repository, and to get in touch about collaboration where it is central to their work.
